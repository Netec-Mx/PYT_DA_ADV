# Análisis de Datos con Python

## Plataforma de laboratorios

Curso práctico de 35 horas que recorre el ciclo de análisis de datos con Python: adquisición, calidad, programación, SQL, estadística, modelado y comunicación de resultados. Integra herramientas modernas y actividades sobre conjuntos de datos aplicados. El curso prepara para la certificación Certified Associate Data Analyst with Python (PCAD-31-02) de Python Institute.


## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.

### Capítulo 1. Adquisición y preprocesamiento de datos

#### [Práctica 1.1. Integrar datos desde archivos, una API y HTML, revisar anonimización y consolidar resultados](Capitulo01/README.md#práctica-integrar-datos-desde-archivos-una-api-y-html-revisar-anonimización-y-consolidar-resultados)

- Descripción: Integrar datos de archivos, una API y una página HTML, revisar el tratamiento de información sensible y consolidar las fuentes en un conjunto de datos para su análisis.
- ⏱️ Duración estimada: 90 min.

#### [Práctica 1.2. Depurar datos, imputar faltantes, codificar categorías, detectar anomalías y aplicar transformaciones reproducibles](Capitulo01/README.md#práctica-depurar-datos-imputar-faltantes-codificar-categorías-detectar-anomalías-y-aplicar-transformaciones-reproducibles)

- Descripción: Limpiar y estandarizar datos mediante el tratamiento de valores faltantes, duplicados y categorías. Detectar anomalías y aplicar transformaciones que puedan reproducirse.
- ⏱️ Duración estimada: 120 min.

#### [Práctica 1.3. Construir controles automáticos de calidad, validar reglas entre campos y generar un conjunto preparado](Capitulo01/README.md#práctica-construir-controles-automáticos-de-calidad-validar-reglas-entre-campos-y-generar-un-conjunto-preparado)

- Descripción: Implementar controles de calidad para comprobar tipos, rangos y relaciones entre campos, registrar los resultados y preparar un conjunto de datos validado.
- ⏱️ Duración estimada: 90 min.

### Capítulo 2. Habilidades de programación y bases de datos

#### [Práctica 2.1. Preparar un entorno, crear un script con funciones y estructuras, administrar paquetes y manejar errores](Capitulo02/README.md#práctica-preparar-un-entorno-crear-un-script-con-funciones-y-estructuras-administrar-paquetes-y-manejar-errores)

- Descripción: Preparar el entorno de Python y desarrollar un script organizado con funciones y estructuras de datos, administrando dependencias y controlando errores.
- ⏱️ Duración estimada: 90 min.

#### [Práctica 2.2. Crear clases de registros y exportación, reutilizar métodos y verificar igualdad de objetos](Capitulo02/README.md#práctica-crear-clases-de-registros-y-exportación-reutilizar-métodos-y-verificar-igualdad-de-objetos)

- Descripción: Modelar registros mediante clases, reutilizar métodos para procesar y exportar información y comprobar las diferencias entre identidad e igualdad de objetos.
- ⏱️ Duración estimada: 60 min.

#### [Práctica 2.3. Ejecutar consultas, CRUD y JOIN, conectar Python con SQLite, convertir tipos y usar consultas parametrizadas](Capitulo02/README.md#práctica-ejecutar-consultas-crud-y-join-conectar-python-con-sqlite-convertir-tipos-y-usar-consultas-parametrizadas)

- Descripción: Conectar Python con SQLite para consultar y modificar datos, combinar tablas y convertir tipos. Utilizar consultas parametrizadas para manejar los valores de entrada.
- ⏱️ Duración estimada: 150 min.

### Capítulo 3. Análisis descriptivo y estadístico

#### [Práctica 3.1. Realizar análisis exploratorio, calcular estadísticas y correlaciones e interpretar distribuciones y anomalías](Capitulo03/README.md#práctica-realizar-análisis-exploratorio-calcular-estadísticas-y-correlaciones-e-interpretar-distribuciones-y-anomalías)

- Descripción: Explorar un conjunto de datos mediante estadísticas descriptivas, correlaciones y gráficos para interpretar distribuciones, relaciones entre variables y valores atípicos.
- ⏱️ Duración estimada: 120 min.

#### [Práctica 3.2. Estimar distribuciones con bootstrapping, ajustar regresiones lineal y logística e interpretar coeficientes](Capitulo03/README.md#práctica-estimar-distribuciones-con-bootstrapping-ajustar-regresiones-lineal-y-logística-e-interpretar-coeficientes)

- Descripción: Aplicar remuestreo mediante bootstrapping y ajustar modelos de regresión lineal y logística, interpretando sus coeficientes y las limitaciones de los resultados.
- ⏱️ Duración estimada: 120 min.

### Capítulo 4. Análisis avanzado y modelado con Python

#### [Práctica 4.1. Crear un pipeline con Pandas/NumPy que filtre con loc/iloc, limpie, combine, pivotee y agregue datos](Capitulo04/README.md#práctica-crear-un-pipeline-con-pandasnumpy-que-filtre-con-lociloc-limpie-combine-pivotee-y-agregue-datos)

- Descripción: Construir un pipeline de transformación con Pandas y NumPy que seleccione, limpie, combine y reestructure datos, y genere agregaciones para el análisis.
- ⏱️ Duración estimada: 210 min.

#### [Práctica 4.2. Entrenar regresión lineal y logística, evaluar con datos de prueba e identificar sobreajuste y sesgo](Capitulo04/README.md#práctica-entrenar-regresión-lineal-y-logística-evaluar-con-datos-de-prueba-e-identificar-sobreajuste-y-sesgo)

- Descripción: Preparar variables, entrenar modelos de regresión lineal y logística y evaluar su desempeño con datos de prueba para identificar sobreajuste y sesgo.
- ⏱️ Duración estimada: 180 min.

### Capítulo 5. Comunicación y visualización de datos

#### [Práctica 5.1. Crear visualizaciones estadísticas con Matplotlib/Seaborn, anotarlas y justificar la selección de gráficos](Capitulo05/README.md#práctica-crear-visualizaciones-estadísticas-con-matplotlibseaborn-anotarlas-y-justificar-la-selección-de-gráficos)

- Descripción: Crear visualizaciones con Matplotlib y Seaborn, incorporar títulos, etiquetas y anotaciones, y justificar qué representaciones comunican mejor los resultados.
- ⏱️ Duración estimada: 120 min.

#### [Práctica 5.2. Desarrollar y presentar un informe ejecutivo con visualizaciones, evidencias y recomendaciones verificables](Capitulo05/README.md#práctica-desarrollar-y-presentar-un-informe-ejecutivo-con-visualizaciones-evidencias-y-recomendaciones-verificables)

- Descripción: Integrar los hallazgos en un informe ejecutivo con visualizaciones, conclusiones respaldadas por evidencia, limitaciones y recomendaciones adaptadas a la audiencia.
